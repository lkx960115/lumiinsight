## 风险与减配

| 风险 | 减配 |
|------|------|
| 导入/权限耗时超预期 | W1 可砍「角色编辑器」，只保留 admin / analyst 两角色 |
| ABSA 效果差 | W2 先词典+LLM JSON，不上训练；指标放到评测集而非当场 85% F1 |
| Qdrant / Embedding 不顺 | W3 可用 MySQL 全文/关键词检索顶上，向量后补 |
| 多模型联调慢 | 先打通 1 个 OpenAI 兼容提供方（智谱），第二个用「自定义 Base URL」验证可切换即可 |
