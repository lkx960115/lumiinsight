# LOCAL_RULES — lumiinsight

只能补充或收紧上层规则。

## 必须

1. 前端 Element Plus；路由 `/app` 与 `/admin` 分布局。  
2. 登录仅本地账号密码 + JWT。  
3. Excel 导入为唯一数据入口（MVP）。  
4. LLM 多提供方后台配置，OpenAI 兼容协议优先。  
5. Java 编排、Python 做重计算。  
6. 改动涉及权限 / Key / 批量导入时，回复开头标注高风险。
7. 工作台按产品标准交付。改页面必须完整遵守 [PRODUCT_UI.md](PRODUCT_UI.md)（按钮层级、列表列顺序、弹窗、空状态），禁止每个页面自造样式。

## 禁止

1. 将本仓放入 `ogsmProject` 当子项目（除非用户改口）。  
2. 实现四平台爬虫或 RPA。  
3. 把 GLM 写死为唯一调用实现。  
4. 在 README 公布初始管理员密码。  
5. 无确认引入 React / Django 站点 / K8s。
