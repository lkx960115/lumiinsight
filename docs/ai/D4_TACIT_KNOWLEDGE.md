# D4 结构化隐性知识 — lumiinsight

代码周之前先记「以后一定会踩」的口径。有生产踩坑再追加。

## 1. 灯具方面词典（MVP 种子）

亮度、色温、外观、材质、安装、质量、售后、价格、物流、频闪、寿命、智能联动、遥控、防水、包装。

ABSA 输出的方面名必须落在词典或「其它」；禁止模型自由发明十几个近义词当新方面。

## 2. 导入

- 同一「平台 + 评论ID」幂等；无评论ID 时用内容哈希。  
- 平台字段不统一：导入时映射到统一 Review，原始行进 JSON 备份列。  
- 失败行要能下载错误报告，不能整文件静默丢弃。

## 3. 去水

先规则后模型。规则打的标签要给人看（广告、模板好评、过短）。不要第一周上图神经网络。

## 4. 报告幻觉

摘要模型只允许改写「统计结果 + 已检索原声」，不允许用训练知识补充竞品事实。

## 5. 公开仓

演示数据不要含真实用户手机号、内部未公开型号策略。
