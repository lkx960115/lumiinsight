# D3 可注入规则库 — lumiinsight

编码与评审强制项。补充见 [LOCAL_RULES.md](LOCAL_RULES.md)。

## 1. 执行闸门

- 用户未说「确认执行 / 开始写代码」时，不生成业务代码。  
- 空仓阶段只允许文档；**2026-09-14 用户已确认按计划写代码**，W1 已落地。

## 2. 安全

- 禁止提交 `.env`、密钥、密码。公开仓按泄露处理。  
- LLM Key 仅加密落库或本机环境变量；接口返回脱敏。  
- 评论脱敏：手机号、详细地址不得明文展示。

## 3. 业务

- 导入模板列变更必须同步 `DOMAIN_LUMI.md`。  
- 结论输出必须带 `evidenceIds`；校验失败不得当成功报告。  
- 分析任务异步，禁止在 HTTP 请求线程里批量调 LLM。

## 4. LLM 配置

- 新增调用点必须走 Route，不得 new 死一个厂商 Client。  
- 后台至少能配两个提供方并切换默认路由。

## 5. 产品界面

正本见 [PRODUCT_UI.md](PRODUCT_UI.md)。摘要：

- 给业务看的产品，不是给开发看的后台。状态/平台用中文，主界面不摊任务 ID 和英文枚举。
- 一屏一个主操作；先结论（概览、有效评论）后明细（处理记录）。
- 所有列表同一套列顺序和样式：主对象 → 属性 → 状态 → 时间 → 操作；禁止 ID 当第一列、禁止把 Java 异常当说明。

## 6. 评审清单

- [ ] 是否把 Key 写进仓库或示例？  
- [ ] 是否越界实现爬虫？  
- [ ] 是否跳过证据校验？  
- [ ] 权限标识前后端是否同名？  
- [ ] 主界面是否把英文状态/平台代码/任务 ID 摊给用户？  
- [ ] 列表是否同一套样式，说明是否可读？  
- [ ] 六维是否要回写？
